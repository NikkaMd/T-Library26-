# T‑Библиотека

Простая консольная библиотека для учёта книг на C++. Проект создан как учебное-отборочное задание на проектную IT смену 

## Функционал

Программа позволяет:
* добавлять книги с указанием названия, автора, жанра, года издания и описания;
* просматривать все книги;
* искать книги по ключевым словам (в названии, авторе или описании);
* сортировать книги по названию, автору или году издания;
* фильтровать книги по жанру и статусу прочтения;
* отмечать книги как прочитанные/непрочитанные;
* добавлять/убирать книги из избранного;
* удалять книги из библиотеки;
* сохранять данные в JSON‑файл между запусками.

## Особенности реализации

* **Хранение данных:** книги сохраняются в файле `books.json` в формате JSON.
* **Библиотека JSON:** используется `nlohmann/json` для сериализации/десериализации объектов `Book`.
* **STL:** активно применяются контейнеры (`std::vector`), алгоритмы (`std::sort`, `std::remove_if`) и итераторы.
* **ООП:** код структурирован в классы (`Library`, `Book`) с инкапсуляцией данных.

## Установка и запуск

### Требования

* компилятор C++17 или новее (например, GCC 7+, Clang 6+);
* библиотека `nlohmann/json` (заголовочный файл);
* стандартная библиотека C++.
